# Book Reading List Application

A web application designed for tracking book reading progress, wishlist management, and library categorization with persistent local storage.

**Author:** Manik Kukkar  
**Degree:** B.Tech Computer Science and Engineering  
**University:** JECRC University, Jaipur  

---

## Features

- **Reading Status Categories:** Organize books into *Currently Reading*, *Completed*, and *Want to Read (Wishlist)*.
- **Real-Time Statistics Dashboard:** Dynamic counts for total books and status categories.
- **Filter Tabs:** Instantly filter collection by status tabs with a single click.
- **Full CRUD Capabilities:** Add new entries, cycle through statuses, and remove books.
- **LocalStorage Persistence:** All library data persists automatically across browser refreshes.

---

## Technologies Used

- **HTML5:** Semantic card layout, form inputs, accessibility.
- **CSS3:** Responsive Grid, CSS custom properties, dark mode aesthetic.
- **JavaScript (ES6+):** Array manipulation, event handling, LocalStorage API.
